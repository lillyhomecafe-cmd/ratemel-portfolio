# Ratemel Portfolio

桜・マカロン・カフェラテをテーマにしたシングルページのポートフォリオサイトです。

## 構成
- `index.html` — HTML
- `style.css` — CSS
- `script.js` — JavaScript
- `assets/macaron-girl.png` — About me のアイコン画像

フレームワーク、ビルドツール、外部ライブラリ不要です。`index.html` をブラウザで開くだけで表示できます。

## 公開方法（GitHub Pages）
1. GitHubで公開リポジトリ（例: `ratemel-portfolio`）を作成します。
2. 3ファイルと `assets` フォルダをリポジトリのルートにアップロードします。
3. リポジトリの Settings → Pages → Build and deployment → Deploy from a branch を選択します。
4. Branchを `main` / `/(root)` に設定して Save します。
5. 公開後のURLは通常 `https://<GitHubユーザー名>.github.io/ratemel-portfolio/` になります。
